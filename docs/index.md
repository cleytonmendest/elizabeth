## Suporte · Support

Dúvida que a documentação não responde, ou algo que parece defeito do tema — <span lang="en">*a question the docs don't answer, or something that looks like a theme bug*</span>:

- [github.com/cleytonmendest/elizabeth/issues](https://github.com/cleytonmendest/elizabeth/issues/new)

Ao relatar, diga **qual página**, **qual seção**, **qual esquema de cores** e **celular ou computador**. <span lang="en">*When reporting, say which page, which section, which color scheme, and phone or desktop.*</span> Sem isso a maioria dos relatos não é reproduzível.
